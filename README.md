# Bootstrap Shop Prototypes

Прототипы страниц интернет-магазина на Bootstrap и простой Python-сервер, который на любой GET-запрос возвращает страницу «Контакты».

## Страницы

| Файл | Описание |
| --- | --- |
| `index.html` | Главная: карточки товаров |
| `categories.html` | Категория 1: сетка из шести карточек |
| `catalog.html` | Каталог: карточки с миниатюрами |
| `contacts.html` | Контакты: форма обратной связи и текст |
| `404.html` | Страница «Не найдено» |
| `500.html` | Страница «Внутренняя ошибка сервера» |

На каждой странице есть хедер, боковое меню, основной блок и футер.

Bootstrap 5 и Bootstrap Icons подключены по CDN, для отображения стилей нужен интернет.

## Запуск сервера

Требуется Python 3.8+. Сторонние библиотеки не нужны.

```bash
python server.py
```

После запуска откройте http://localhost:8000. Любой GET-запрос (например, `/abc` или `/?x=1`) вернёт страницу «Контакты».

Сервер отдаёт ответ с заголовком `Content-type: text/html; charset=utf-8`. Содержимое читается из `contacts.html` через `with open()`.

## Поведение сервера

- `GET` на любой путь возвращает страницу «Контакты».
- `GET` на путь к файлу с другим расширением (например, `/favicon.ico`) возвращает `404.html`.
- `POST` принимает данные формы и выводит их в консоль, в ответ возвращается страница «Контакты».
- Если HTML-файл не удалось прочитать, сервер возвращает `500.html`.

## Проверка

```bash
curl -i http://localhost:8000/any/path
```

В ответе должны быть статус `200 OK` и заголовок `Content-type: text/html`.

Проверка POST (данные появятся в консоли сервера):

```bash
curl -d "name=Вася&email=a@b.c&message=Привет" http://localhost:8000/
```

Также можно заполнить форму на странице «Контакты» и нажать «Отправить».

## Примечания

- Запускайте `server.py` из папки проекта, иначе `contacts.html` не будет найден.
- Остальные страницы можно смотреть, открывая HTML-файлы напрямую в браузере: сервер всегда отдаёт только «Контакты».
